## 1. Wat is hepatische lipidose?

### Definitie

Hepatische lipidose (HL) is een klinisch syndroom waarbij **overmatige triglyceriden ophopen in hepatocyten** (levercellen). Bij ernstige gevallen is meer dan 80% van het cytoplasma van de levercellen gevuld met vetvacuolen. Het levergewicht neemt met meer dan 50% toe, wat leidt tot ernstige leverdisfunctie en cholestase (verminderde galafvoer).

### Epidemiologie

- **Meest voorkomende verworven leverziekte bij katten** (~50% van alle leverbiopten)
- Prevalentie: ~0.16% in eerstelijns veterinaire praktijken
- Vooral in Noord-Amerika, Groot-Brittannië, Japan en West-Europa (correlatie met obesitascijfers)
- **Leeftijd:** alle leeftijden (3 maanden – 25 jaar), piek bij middelbare leeftijd
- **Geslacht:** vrouwelijke katten ~2:1 oververtegenwoordigd
- **Risicoprofiel:** overwegend obese katten die een periode van anorexie doormaken
- Typisch >25% gewichtsverlies bij presentatie

### Primair vs. secundair

| Type | Percentage | Oorzaak |
|------|-----------|---------|
| **Secundair** | ~95% | Onderliggend ziekteproces veroorzaakt anorexie (diabetes mellitus, pancreatitis, IBD, cholangitis, nierinsufficiëntie, neoplasie, hyperthyreoïdie) |
| **Primair (idiopathisch)** | ~5% | Anorexie door stress, verhuizing, verandering in voeding, verblijf in pension |

### Klinische verschijnselen (kort)

Lethargie, anorexie, icterus (gele slijmvliezen/oren), hepatomegalie, speekselen (nausea), braken, nekventroflexie (thiaminedeficiëntie), gewichtsverlies.

## 2. Waarom zijn katten uniek gevoelig?

Katten zijn **obligate carnivoren** met een metabolisme dat fundamenteel verschilt van omnivoren en herbivoren. Dit maakt hun lever extreem kwetsbaar bij vasten.

### 2.1 Constitutief hoog eiwitkatabolisme

Katten kunnen hun hepatische aminozuurafbraak-enzymen (transaminasen, ureumcyclus-enzymen) **niet downreguleren** bij lage eiwitinname. Bij omnivoren en honden daalt de activiteit van deze enzymen bij vasten — bij katten blijft deze onveranderd hoog. Dit betekent dat tijdens anorexie aminozuren in hoog tempo worden afgebroken, ook al komen er geen nieuwe binnen via het dieet.

### 2.2 Permanente gluconeogenese

De lever van de kat staat permanent "aan" voor gluconeogenese uit aminozuren. De enzymen pyruvaat carboxylase, fructose-1,6-bisfosfatase en glucose-6-fosfatase zijn constitutief actief op hoog niveau. De kat produceert glucose primair uit aminozuurkoolstofskelettten, niet uit koolhydraten.

### 2.3 Essentiële nutriënten die katten niet (voldoende) kunnen synthetiseren

| Nutriënt | Waarom essentieel bij de kat? |
|----------|-------------------------------|
| **Taurine** | Lage activiteit cysteïnesulfinezuur decarboxylase; obligate conjugatie van galzouten met taurine (niet glycine) |
| **Arginine** | Geen intestinale ornithinesynthese (lage pyrroline-5-carboxylaat synthase); essentieel voor ureumcyclus |
| **Arachidonzuur** | Ontbrekende/lage delta-6-desaturase → kan linolzuur niet omzetten |
| **Vitamine A** | Geen bèta-caroteen-15,15'-dioxygenase → kan bèta-caroteen niet splitsen |
| **Niacine (B3)** | Hoge picolinezuur carboxylase activiteit → tryptofaan wordt niet omgezet in niacine |
| **Vitamine D** | Hoge 7-dehydrocholesterol-delta-7-reductase → onvoldoende cutane synthese |

### 2.4 Beperkte koolhydraatvertering

- **Geen speekselamylase**
- Pancreatisch amylase slechts ~5% van het hondenniveau
- Geen lactase en sucrase bij volwassen katten
- Nauwelijks hepatisch glucokinase → beperkte glucoseverwerking
- **Aminozuren zijn krachtigere insulinesecretagogen** dan glucose

### 2.5 Hoge B-vitaminebehoefte

Katten hebben op basis van metabool lichaamsgewicht aanzienlijk meer B-vitamines nodig:
- Cobalamine (B12): ~5× de humane behoefte
- Choline: ~2,5× de humane behoefte
- Niacine: 4× de behoefte van honden

## 3. Het mechanisme: hoe ontstaat leververvetting?

### Het kernprobleem

HL ontstaat door een **pathologische disbalans** tussen:

- **Instroom:** vetzuren die vanuit perifeer vetweefsel (lipolyse) naar de lever stromen
- **Uitstroom/verwerking:** het vermogen van de lever om vetzuren te oxideren (bèta-oxidatie) of te exporteren als VLDL

### Stap-voor-stap mechanisme

```
┌─────────────────────────────────────────────────────────────────┐
│                    ANOREXIE / VASTEN                            │
│                         │                                       │
│                         ▼                                       │
│              ↓ Insuline, ↑ Catecholaminen                       │
│                         │                                       │
│                         ▼                                       │
│         Hormoon-sensitieve lipase geactiveerd                   │
│              in VETWEEFSEL (lipolyse)                           │
│                         │                                       │
│                         ▼                                       │
│     Massale mobilisatie vrije vetzuren (NEFA's)                 │
│          gebonden aan albumine → bloed → LEVER                  │
│                         │                                       │
│            ┌────────────┼────────────┐                          │
│            ▼            ▼            ▼                           │
│      Bèta-oxidatie   VLDL-export   Re-esterificatie             │
│       (verminderd)   (verminderd)   tot triglyceriden           │
│            │            │            │                           │
│            ▼            ▼            ▼                           │
│     Carnitine-      Tekort aan:   TRIGLYCERIDEN                 │
│     insufficiëntie  • ApoB100     STAPELEN OP                   │
│     blokkeert       • Fosfatidyl-  IN HEPATOCYTEN               │
│     vetzuurtransport  choline                                   │
│     naar mitochondriën• ApoE                                    │
│                         │                                       │
│                         ▼                                       │
│              HEPATISCHE LIPIDOSE                                │
│         (cholestase, leverfalen)                                 │
│                         │                                       │
│                         ▼                                       │
│        Nausea → verdere anorexie → VICIEUZE CIRKEL              │
└─────────────────────────────────────────────────────────────────┘
```

### Stap 1 — Perifere lipolyse

Bij anorexie dalen insulinespiegels en stijgen catecholaminen. **Hormoon-sensitieve lipase** in adipocyten wordt geactiveerd. Vrije vetzuren (NEFA's / FFA's) worden gemobiliseerd uit vetopslagplaatsen en via albumine naar de lever getransporteerd. Bij **obese katten** is deze mobilisatie dramatisch groter door de uitgebreide vetreserves.

### Stap 2 — Verminderde bèta-oxidatie

In de hepatocyt moeten langketenige vetzuren via het **carnitine-shuttlesysteem** (CPT-I → translocase → CPT-II) de binnenste mitochondriële membraan passeren voor bèta-oxidatie.

Probleem: er ontstaat een **relatieve carnitine-insufficiëntie**. De vraag naar carnitine overtreft het synthesevermogen. Carnitinesynthese is afhankelijk van:
- **Lysine** (koolstofskelet)
- **SAMe** (uit methionine — methylering)
- **IJzer, B-vitamines** (cofactoren)

Al deze precursors raken uitgeput tijdens anorexie.

### Stap 3 — Verminderde VLDL-export

Triglyceriden worden normaal als VLDL-deeltjes geëxporteerd. VLDL-assemblage vereist:

| Component | Functie | Waarom tekort bij HL? |
|-----------|---------|----------------------|
| **Apolipoproteïne B100** | Structureel eiwit van VLDL | Eiwit-/aminozuurtekort door anorexie |
| **Fosfatidylcholine (PC)** | Fosfolipidemantel van VLDL | Synthese vereist SAMe (methionine) of choline — beide uitgeput |
| **Apolipoproteïne E** | Verhoogt VLDL-secretie | Synthese vereist arginine — uitgeput |

**Belangrijk:** katten met HL tonen hypertriglyceridemie (verhoogd VLDL in plasma), wat aantoont dat er *enige* VLDL-secretie plaatsvindt — maar deze is **onvoldoende** t.o.v. de instroom.

### Stap 4 — Paradoxale de novo lipogenese

Paradoxaal genoeg worden enzymen voor hepatische vetzuursynthese (ACC-1, FAS) **opgereguleerd** tijdens vasten bij katten. Acetaat (niet glucose) dient als koolstofbron, wat de vetbelasting verder verhoogt.

### Stap 5 — Oxidatieve stress

De partiële bèta-oxidatie die wél plaatsvindt genereert reactieve zuurstofvormen. **Glutathion (GSH)** — het belangrijkste antioxidant — raakt uitgeput omdat de synthese afhankelijk is van cysteïne (uit methionine, via het transsulfuratiepad). Dit veroorzaakt verdere mitochondriële schade.

### Stap 6 — Vicieuze cirkel

Leverdisfunctie → nausea → verdere anorexie → meer lipolyse → meer vetophoping → ergere leverdisfunctie.

## 4. Nutriëntcategorieën en hun vertering bij de kat

### 4.1 Overzicht verteringsstelsel van de kat

| Orgaan | Kenmerken bij de kat |
|--------|---------------------|
| **Mond** | 30 tanden voor scheuren/knippen (geen maalvlak); geen speekselamylase; beperkte laterale kaakbeweging |
| **Slokdarm** | ~22-23 cm; peristaltisch transport |
| **Maag** | ~300-350 mL; pH 1-2; pariëtaalcellen (HCl), hoofdcellen (pepsinogeen), slijmcellen |
| **Dunne darm** | Totaal ~1-1,5 m (kort: ~3× romplengte vs. ~6× bij omnivoren) |
| — Duodenum | 14-16 cm; ontvangst van gal + pancreassap |
| — Jejunum | ~130 cm; langste segment; hoofdlocatie nutriëntabsorptie |
| — Ileum | Zeer kort (~2,5 cm); B12-absorptie; galzoutrecirculatie |
| **Blinde darm (cecum)** | Slechts 2-3 cm (minimale fermentatie) |
| **Dikke darm (colon)** | ~33 cm; waterabsorptie; fermentatie van vezels → korteketenvetzuren |
| **Lever** | ~2% lichaamsgewicht; 6 lobben; galproductie; centraal in metabolisme |
| **Pancreas** | ~12 cm; exocriene enzymen + bicarbonaat |

### 4.2 Eiwitten

**Behoefte:** 50-60% van de energie-inname; 2-3× hoger dan bij omnivoren.

**Afbraak:**

| Locatie | Proces | Enzymen |
|---------|--------|---------|
| **Maag** | Denaturatie + initiële hydrolyse | HCl denatureert; pepsinogeen → **pepsine** (door HCl); klieft eiwitten in grote polypeptiden |
| **Dunne darm (lumen)** | Pancreatische proteolyse | Enterokinase activeert trypsinogeen → **trypsine**; trypsine activeert **chymotrypsine**, **carboxypeptidase**, **elastase** |
| **Dunne darm (borstelzoom)** | Eindhydrolyse | **Aminopeptidasen** en **dipeptidasen** → vrije aminozuren, di-/tripeptiden |

**Absorptie (duodenum + jejunum):**
- Vrije aminozuren: **Na⁺-gekoppeld actief transport** (specifieke carriers voor neutrale, basische, zure en imino-aminozuren)
- Di-/tripeptiden: **PepT1-transporter** (H⁺-gekoppeld cotransport)
- Basolateraal: gefaciliteerde diffusie naar poortaderbloed

### 4.3 Vetten/lipiden

**Behoefte:** 25-35% van de energie-inname.

**Afbraak:**

| Locatie | Proces | Agentia |
|---------|--------|---------|
| **Maag** | Minimale lipolyse | Volwassen katten hebben nauwelijks maag-lipase en **geen linguaal lipase** |
| **Duodenum** | Emulgatie | **Galzouten** uit de galblaas verlagen oppervlaktespanning → kleine emulsiedruppels |
| **Duodenum/jejunum** | Enzymatische hydrolyse | **Pancreaslipase** (+ colipase) klieft triglyceriden op sn-1 en sn-3 posities → **2-monoacylglycerol + vrije vetzuren**; fosfolipase A2; cholesterolesterase |
| **Dunne darm (lumen)** | Micelvorming | Galzouten + vetzuren + monoglyceriden + cholesterol + vetoplosbare vitamines → **gemengde micellen** |

**Absorptie (duodenum + jejunum):**
1. Micellen transporteren lipiden naar de borstelzoom
2. **Passieve diffusie** van vetzuren + 2-monoacylglycerol over apicale membraan (ook CD36, FATP4)
3. In de enterocyt: **re-esterificatie** tot triglyceriden (glad ER)
4. Verpakking in **chylomicronen** (met ApoB-48, cholesterol, fosfolipiden)
5. Exocytose in **lactealen** (lymfevaten) → ductus thoracicus → systemische circulatie
6. **Kort- en middenketenige vetzuren** (C4-C12) gaan direct naar poortaderbloed
7. **Galzouten** worden gerecirculeerd via actief transport in het **terminale ileum** (enterohepatische kringloop; ~95% hergebruik)

### 4.4 Koolhydraten

**Behoefte:** <15% van de energie-inname (lage tolerantie).

**Afbraak:**

| Locatie | Proces | Enzymen |
|---------|--------|---------|
| **Mond** | Geen | Geen speekselamylase |
| **Maag** | Geen | — |
| **Dunne darm (lumen)** | Zetmeelhydrolyse | **Pancreatisch amylase** (~5% van hondenniveau) → maltose, maltotriose, dextrinen |
| **Dunne darm (borstelzoom)** | Disacharidehydrolyse | Lage maltase-activiteit; **geen lactase en sucrase** bij volwassen katten; activiteit kan NIET worden opgereguleerd |

**Absorptie (jejunum):**
- Glucose/galactose: **SGLT1** (Na⁺-glucose cotransporter) — ~2× langzamer dan bij honden; exit via **GLUT2**
- Fructose: **GLUT5** (gefaciliteerde diffusie); exit via GLUT2
- Katten missen het T1R2 sweetreceptorsubunit → kunnen SGLT1 niet opreguleren bij koolhydraatrijk dieet

### 4.5 Vitamines

**Vetoplosbaar (A, D, E, K):**
- Absorptie in **duodenum + jejunum**
- Vereisen micelvorming (galzouten + dieetvetten) → passieve diffusie over enterocytmembraan
- Verpakking in chylomicronen → lymfetransport
- Opslag in lever en vetweefsel

**Wateroplosbaar (B-complex):**
- Absorptie voornamelijk in **jejunum** via specifieke carrier-gemedieerde transportsystemen
- **Vitamine B12 (cobalamine):** uniek — bindt aan intrinsic factor (uit pariëtaalcellen) → receptorgemedieerde endocytose via cubiline in het **terminale ileum**
- Microbieel gesynthetiseerde vitamines (biotine, foliumzuur, vitamine K): absorptie in **dikke darm**

### 4.6 Mineralen

| Mineraal | Absorptielocatie | Mechanisme |
|----------|-----------------|------------|
| **Calcium** | Duodenum (actief), jejunum/ileum/colon (passief) | TRPV6-kanalen + calbindine (vit. D-afhankelijk) / paracellulair |
| **Fosfor** | Duodenum/jejunum | NaPi-IIb cotransporter (vit. D-afhankelijk) |
| **IJzer** | Proximaal duodenum | Ferrireductase → DMT1 (Fe²⁺ + H⁺); heem via endocytose; export via ferroportine |
| **Zink** | Jejunum | Niet volledig opgehelderd; dierlijk eiwit bevordert absorptie |
| **Koper** | Duodenum/jejunum | Ctr1-transporter; export via ATP7A |
| **Magnesium** | Jejunum/ileum/colon | TRPM6/7 (actief) + paracellulair (passief) |
| **Na⁺, K⁺, Cl⁻** | Dunne + dikke darm | Diverse ionkanalen en transporters |

### 4.7 Water

- Absorptie door **osmose** door heel de dunne en dikke darm
- Katten zijn geëvolueerd als woestijndieren met een **lage dorstdrang**
- Prooidieren bevatten ~70% vocht → droogvoer leidt tot chronische milde dehydratie

## 5. De rol van specifieke voedingsstoffen in leververvetting

### 5.1 L-Carnitine — Vetzuurtransport naar mitochondriën

```
Vetzuur + CoA → Acyl-CoA
        │
        ▼ CPT-I (buitenmembraan)
Acyl-CoA + L-Carnitine → Acylcarnitine
        │
        ▼ Translocase
        │
        ▼ CPT-II (binnenmembraan)
Acylcarnitine → Acyl-CoA + L-Carnitine (hergebruik)
        │
        ▼
   Bèta-oxidatie in matrix
```

- **Synthese vereist:** lysine + SAMe (methionine) + vitamine C + B6 + niacine + ijzer
- **Bij HL:** relatieve insufficiëntie — vraag >> aanbod; precursors uitgeput
- **Supplementatie** beschermt tegen leververvetting bij energierestrici

### 5.2 Methionine & Choline — Methyldonoren en VLDL-assemblage

```
Methionine → SAMe (S-adenosylmethionine)
               │
    ┌──────────┼───────────────────────┐
    ▼          ▼                       ▼
PC-synthese  Carnitine-            Glutathion-
(PEMT-pad)   synthese              synthese
    │       (methylering lysine)   (via cysteïne)
    ▼
VLDL-mantel
(export TG uit lever)
```

- **Methionine** is de universele methyldonor (via SAMe) voor:
  - Fosfatidylcholine (PC) → VLDL-export
  - Carnitinesynthese → bèta-oxidatie
  - Glutathion → antioxidantbescherming
  - Creatine, DNA/RNA-methylering
- **Choline** wordt direct ingebouwd in PC via het CDP-choline (Kennedy) pad, of geoxideerd tot **betaïne** (alternatieve methyldonor)
- Bij HL daalt plasma-methionine met >50%
- Kattenbehoeften: methionine 0,038 g/kg LG⁰·⁷⁵; choline 57,0 mg/kg LG⁰·⁷⁵

### 5.3 Arginine — Ureumcyclus en VLDL

- **Ureumcyclus:** arginine → (arginase) → ureum + ornithine
- Katten kunnen ornithine niet zelf synthetiseren → **volledig afhankelijk van dieet-arginine**
- Eén arginine-vrije maaltijd kan binnen 2-5 uur fatale hyperammoniëmie veroorzaken
- Arginine is ook nodig voor **ApoE-synthese** (VLDL-export)
- Bij HL: dubbele competitie — ureumcyclus vs. VLDL-assemblage
- Plasmaconcentratie daalt >50% bij HL

### 5.4 Taurine — Galzoutconjugatie

- Katten zijn **obligate taurine-conjugeerders**: galzouten worden uitsluitend met taurine geconjugeerd (niet glycine)
- Taurine-geconjugeerde galzouten zijn essentieel voor **micelvorming** en vetvertering
- Bacteriële deconjugatie in de darm → taurineverlies → continue drain
- Bij taurinedeficiëntie: verminderde galzuurconcentratie in gal, verstoorde vetstofwisseling
- Andere gevolgen deficiëntie: feline centrale retinale degeneratie (blindheid), dilatatieve cardiomyopathie, reproductiestoornissen

### 5.5 Essentiële vetzuren — Regulatie genexpressie

- Katten hebben beperkte delta-6-desaturase → **arachidonzuur is essentieel**
- Vetweefsel bevat overwegend verzadigde/enkelvoudig onverzadigde vetzuren
- PUFA's reguleren:
  - **PPARα activatie** → stimuleert hepatische bèta-oxidatie
  - **SREBP-1c suppressie** → remt de novo lipogenese
- Bij HL: relatief PUFA-tekort → verminderde oxidatie + doorgaande lipogenese
- n-6/n-3 ratio stijgt dramatisch bij HL (45-46 vs. 12-14 bij gezonde katten)

### 5.6 B-vitamines — Metabole cofactoren

| Vitamine | Rol in vetstofwisseling | Relevantie bij HL |
|----------|------------------------|--------------------|
| **B12 (cobalamine)** | Cofactor methioninesynthase (homocysteïne → methionine) + methylmalonyl-CoA mutase | 40% van HL-katten heeft subnormaal B12; verstoort hele methylatiesysteem |
| **B1 (thiamine)** | Cofactor pyruvaatdehydrogenase, α-ketoglutaraatdehydrogenase | Deficiëntie → lactaatacidose + encefalopathie (nekventroflexie) |
| **B6 (pyridoxine)** | Cofactor transsulfuratie (homocysteïne → cysteïne) | Deficiëntie → verminderde glutathion- en taurinesynthese |
| **B3 (niacine)** | Precursor NAD⁺/NADP⁺ (bèta-oxidatie, citroenzuurcyclus) | Katten kunnen niacine niet uit tryptofaan synthetiseren |
| **B9 (foliumzuur)** | Methyldonor voor B12-afhankelijke methionineregeneratie | Deficiëntie → functioneel methionine tekort |
| **B2 (riboflavine)** | Precursor FAD/FMN (acyl-CoA dehydrogenasen in bèta-oxidatie) | Verminderde bèta-oxidatiecapaciteit |

## 6. Obesitas als risicofactor

### Het two-hit model

1. **Eerste hit — Obesitas:** chronische overvoeding → uitgebreide vetopslag + insulineresistentie
2. **Tweede hit — Anorexie:** elke trigger die eetlust verlaagt → massale lipolyse uit de enorme vetreserves

### Waarom obesitas het risico vergroot

| Factor | Mechanisme |
|--------|-----------|
| **Grotere vetreserves** | Meer NEFA-mobilisatie bij vasten — grotere vetovervloed naar de lever |
| **Insulineresistentie** | Verminderde lipolysesuppressie → vetweefsel "lekt" vetzuren zelfs bij mild vasten |
| **Adipokine-dysregulatie** | ↓ Adiponectine (insulinesensitiserend), leptineresistentie, ↑ TNF-α |
| **Dyslipidemie** | VLDL-triglyceriden gemiddeld **500% hoger** bij obese vs. slanke katten |
| **Hogere basale levertriglyceriden** | De lever is al "voorbelast" → minder marge voordat steatose klinisch relevant wordt |
| **Metabole inflexibiliteit** | Verminderd vermogen om tussen brandstofbronnen te schakelen |

## 7. Dieetaanpassingen: behandeling en preventie

### 7.1 Behandeling

#### Voedingsondersteuning (hoeksteen van de behandeling)

**Voedingsroute:**
- Meeste HL-katten zijn volledig anorectisch → **enterale voeding via sonde**
- Naso-oesofageale sonde (eerste dagen) of oesofagostomiesonde (weken-maanden)
- Enteraal > parenteraal (behoud darmmotiliteit en villeuze integriteit)

**Refeeding protocol (ter voorkoming van refeedingsyndroom):**

| Dag | Calorisch doel | Frequentie |
|-----|---------------|------------|
| Dag 1 | 25-33% van RER* | 6-8 kleine porties |
| Dag 2 | 50-67% van RER | 5-6 porties |
| Dag 3+ | Opbouw naar 100% RER | 4-6 porties |

*RER (Resting Energy Requirement) = 70 × (lichaamsgewicht in kg)⁰·⁷⁵

**Dieetcompositie:**

| Macronutriënt | % van ME | Reden |
|---------------|----------|-------|
| **Eiwit** | 30-45% | Leverregeneratie, apolipoproteïnesynthese, aminozuurherstel |
| **Vet** | ~50% | Energiedicht, goed verdragen |
| **Koolhydraten** | <20% | Glucoseintolerantie bij HL |

**Specifieke supplementatie:**

| Supplement | Dosis | Reden |
|-----------|-------|-------|
| **L-Carnitine** | 200-250 mg/kat/dag | Bèta-oxidatie faciliteren |
| **Taurine** | 250-500 mg/kat q12u | Galzuurconjugatie, membraanintegriteit |
| **Arginine** | ~1 g/kat/dag | Ureumcyclusfunctie, ApoE-synthese |
| **Cobalamine (B12)** | 250 µg/kat/week SC | Methionineregeneratie |
| **Thiamine (B1)** | 100-200 mg/dag | Voorkomen encefalopathie |
| **Vitamine K** | 1-1,5 mg/kg q12-24u SC | Coagulopathie door cholestase |
| **SAMe** | Volgens label | Methyldonor, glutathionprecursor |
| **Vitamine E** | Volgens label | Antioxidantbescherming |

**Refeedingsyndroom — te monitoren:**
- **Hypofosfatemie** (hallmark) → hemolytische anemie, verminderde ATP-synthese
- **Hypokaliëmie** → spierzwakte, hartritmestoornissen, ileus
- **Hypomagnesiëmie** → refractaire hypokaliëmie, hartritmestoornissen

#### Prognose

- Met intensieve zorg: **75-80% overleving**
- Sondevoeding vaak nodig voor **3-6 weken**
- Katten die herstellen recidiveren zelden
- Positief teken: bilirubine daalt >50% binnen 7-10 dagen

### 7.2 Preventie

| Maatregel | Details |
|-----------|---------|
| **Gewichtsmanagement** | Voorkom obesitas; indien afvallen nodig: max 0,5-2% lichaamsgewicht/week; **nooit** plots streng calorisch beperken |
| **Voedselinname monitoren** | Dagelijks controleren; als kat >24-48 uur weigert → dierenarts |
| **Dieetovergangen** | Altijd geleidelijk over 7-10 dagen |
| **Stressmanagement** | Extra aandacht bij verhuizing, nieuwe huisgenoten, pension |
| **Voedingskwaliteit** | Hoogwaardig, eiwitrijk dieet met voldoende methionine, taurine, arginine, carnitine, B-vitamines en essentiële vetzuren |

### Wat moet in de infographic (kernboodschap, visueel):

1. **Centraal schema:** Het mechanisme in 5-6 stappen (anorexie → lipolyse → leveroverbelasting → falende bèta-oxidatie + VLDL-export → vetophoping → leverfalen). Dit is het hart van de infographic.

2. **De kat als obligate carnivoor — 3-4 bulletpoints:** waarom katten uniek kwetsbaar zijn (hoog eiwitkatabolisme dat niet downreguleert, essentiële nutriënten die niet gesynthetiseerd worden, beperkte koolhydraatvertering).
